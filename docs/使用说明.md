# Magic Photo · 完全本地版

通缉令海报生成器，所有渲染、照片处理与文件保存都在本机完成，不依赖网络、不上传照片。

## 直接使用

Windows 与 Android 用户可直接使用 `release` 文件夹中的成品：

| 文件 | 用途 |
| --- | --- |
| `MagicPhoto-1.0.0-portable.exe` | 免安装便携版，双击即可运行，可复制到任意文件夹或 U 盘 |
| `MagicPhoto-1.0.0-setup.exe` | 安装版，按向导安装到当前用户，创建开始菜单/桌面快捷方式 |
| `MagicPhoto-1.0.0-Android.apk` | Android 7.0+ arm64，使用调试证书签名，可直接安装测试 |
| `MagicPhoto-Offline.html` | 单文件网页版，双击后用浏览器打开即可，完全离线 |

Android APK 只适合本地安装测试；公开分发或上架前请配置自己的签名。macOS、Linux、iOS 与 OpenHarmony 使用同一份页面，可按 [跨平台构建.md](跨平台构建.md) 在对应系统构建。macOS/Linux 桌面版、Android APK 与 iOS 工程共享完全相同的离线保存逻辑。

## 完全本地说明

- 界面样式（WinUI 3 主题、图标字体）已全部内嵌，不再引用任何 CDN。
- 海报由 Canvas 在本地实时绘制，生成 1200 × 1600 PNG，不调用服务器或 AI 接口。
- 照片只在应用内存中暂存，不会上传，也不会写入本地存储；关闭应用后自动清除。
- 点击“下载海报”会打开系统原生保存界面，直接写入你选择的位置；Android 使用 SAF，iOS 使用文档选择器。
- 应用运行时没有任何网络请求。Tauri 版本的 CSP 禁止外部资源，Android 与 OpenHarmony 工程不声明网络权限。

## 运行环境

- Windows 10 / Windows 11，64 位。桌面版使用系统自带的 Microsoft Edge WebView2 运行时（Windows 11 及绝大多数 Windows 10 已预装）。
- macOS 10.15+；Linux 需要 WebKitGTK 4.1 与 GTK 3；Android 7.0+；iOS 15+。
- OpenHarmony 5.0+（实验性）。
- 如果 Windows 缺少 WebView2，可从微软官网安装 Evergreen Runtime 后再运行。
- 单文件网页版支持最新版 Edge / Chrome / Firefox。

## 从源码构建

需要 Node.js、Rust 与对应平台的构建工具。Windows 使用 MSVC 工具链。

```bash
npm install
npm run package        # 构建当前平台成品并整理到 release/
npm run build          # 只生成当前平台安装包
npm run build:portable # Windows：只生成便携 exe
npm run offline-html   # 只生成单文件离线网页
npm run site:build     # 生成 GitHub Pages 网页版（样式从网络加载）
npm run android:build -- --apk   # Android APK
npm run ios:build                # iOS（macOS）
```

各平台依赖、Android SDK/NDK 版本与 OpenHarmony 工程说明见 [跨平台构建.md](跨平台构建.md)。

构建产物：

- `release/MagicPhoto-1.0.0-portable.exe`
- `release/MagicPhoto-1.0.0-setup.exe`
- `release/MagicPhoto-1.0.0-Android.apk`（当前平台已构建 Android APK 时）
- `release/MagicPhoto-Offline.html`
- `release/使用说明.md` 与 `release/SHA256SUMS.txt`
- 原始构建文件位于 `src-tauri/target/release/`、`src-tauri/gen/android/app/build/` 与 `dist/`

## 项目结构

```
index.html                       源页面（本地 CSS 引用）
assets/winui/                    本地化的 WinUI 3 样式与图标字体
scripts/prepare-dist.mjs         将 CSS 内联，生成单文件离线页面
scripts/build-site.mjs           生成样式从网络加载的 GitHub Pages 网页版
scripts/package-release.mjs      整理各平台成品与校验文件
scripts/sync-openharmony.mjs     将离线页面同步到 OpenHarmony rawfile
site/                            GitHub Pages 构建输出
src-tauri/                       Tauri 桌面/移动壳与原生保存命令
src-tauri/gen/android/           Android Studio 工程
dist/                            构建后的单文件页面
openharmony/                     OpenHarmony ArkTS Web 壳（实验性）
release/                         已打包的成品
```
